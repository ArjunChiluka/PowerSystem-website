# Power System Corporate Website

A modern and responsive corporate website developed for an Electrical Switchgear & Control Panel Manufacturing Company.

This website is designed to present the company's profile, products, manufacturing capabilities, certifications, and contact information in a clean, professional, and user-friendly way.

## Features

- Responsive design for all devices
- Modern and clean user interface
- Smooth scrolling navigation
- Professional Hero section
- About Company
- Products & Services
- Manufacturing Facility
- Quality Assurance
- Certifications
- Major Clients
- Gallery
- Contact Information
- Social Media Links
- Optimized for performance

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Project Structure

```text
PowerSystem-website/
│
├── assets/
├── index.html
├── index.css
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click **index.html** or open it in any web browser.

No installation is required.

## Purpose

This project was created to build a professional corporate website with a modern design and a smooth user experience.
